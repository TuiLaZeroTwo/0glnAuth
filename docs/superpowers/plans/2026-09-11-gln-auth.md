# 0glnAuth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `gln-auth`, a Pumpkin Rust WASM plugin with SQLite accounts, Argon2 passwords, sessions, freeze-before-login, and Mojang premium auto-login.

**Architecture:** Single crate at repo root compiling to `wasm32-wasip2` cdylib. Pure logic modules (`config`, `storage`, `hash`, `session`, `premium`, `validation`) are unit-tested with `cargo test`; thin Pumpkin glue (`lib.rs`, `commands.rs`, `handlers.rs`) wires commands and join/leave events.

**Tech Stack:** Rust (edition 2024 per Pumpkin docs, fallback 2021 if toolchain rejects), `pumpkin-plugin-api`, `pumpkin-plugin-utils` (optional), `serde` + `toml`, `rusqlite` with `bundled`, `argon2` 0.5, `serde_json`, `tracing`.

**Spec:** `docs/superpowers/specs/2026-09-11-gln-auth-design.md`

## Global Constraints

- Server under test must run `online_mode=false` / `authentication.enabled=false`, otherwise register/login is meaningless.
- Plugin output is `target/wasm32-wasip2/release/*.wasm`, installed by copying into server `plugins/` dir.
- Fail closed: corrupt DB, hashing failure, or unknown error must deny login, never auto-allow.
- No email/SMTP in v1; no captcha, anti-bot, GeoIP, or 2FA in v1.
- Store `isPremium = premium_id IS NOT NULL`; session resume iff `now < expires AND ip == last_ip`.
- Default policy values: timeout 120s, session 120min, `max_login_tries` 5, pw length 8..64, premium cache 45min.

```rust
use crate::config::PluginConfig;

pub fn normalize_name(name: &str) -> String {
    name.to_lowercase()
}

pub fn validate_name(name: &str) -> Result<(), String> {
    if name.len() < 3 || name.len() > 16 {
        return Err("Name must be 3-16 chars.".to_string());
    }
    if !name.chars().all(|c| c.is_ascii_alphanumeric() || c == '_') {
        return Err("Name may only contain a-z A-Z 0-9 _.".to_string());
    }
    Ok(())
}

pub fn validate_password(pw: &str, name: &str, cfg: &PluginConfig) -> Result<(), String> {
    if pw.len() < cfg.pw_min_len || pw.len() > cfg.pw_max_len {
        return Err(format!(
            "Password must be {}-{} chars.",
            cfg.pw_min_len, cfg.pw_max_len
        ));
    }
    if pw.to_lowercase().contains(&name.to_lowercase()) {
        return Err("Password must not contain your name.".to_string());
    }
    Ok(())
}
```

```rust
use argon2::{
    Argon2,
    password_hash::{PasswordHash, PasswordHasher, PasswordVerifier, SaltString, rand_core::OsRng},
};

pub fn hash_password(pw: &str) -> Result<String, String> {
    let salt = SaltString::generate(&mut OsRng);
    Argon2::default()
        .hash_password(pw.as_bytes(), &salt)
        .map(|h| h.to_string())
        .map_err(|e| format!("hash failed: {e}"))
}

pub fn verify_password(hash: &str, pw: &str) -> bool {
    let parsed = match PasswordHash::new(hash) {
        Ok(p) => p,
        Err(_) => return false,
    };
    Argon2::default()
        .verify_password(pw.as_bytes(), &parsed)
        .is_ok()
}
```

```rust
use rusqlite::{Connection, OptionalExtension, params};
use std::sync::Mutex;

#[derive(Debug, Clone)]
pub struct Account {
    pub name: String,
    pub uuid: String,
    pub premium_id: Option<String>,
    pub hash: String,
    pub last_ip: String,
    pub last_seen: i64,
    pub created: i64,
}

#[derive(Debug, Clone)]
pub struct Session {
    pub name: String,
    pub ip: String,
    pub expires_at: u64,
}

pub struct AuthStore {
    conn: Mutex<Connection>,
}

impl AuthStore {
    pub fn open(path: &str) -> Result<Self, String> {
        let conn = Connection::open(path).map_err(|e| format!("open db: {e}"))?;
        conn.execute_batch(
            "CREATE TABLE IF NOT EXISTS accounts(
              name TEXT PRIMARY KEY, uuid TEXT NOT NULL, premium_id TEXT,
              hash TEXT NOT NULL, last_ip TEXT NOT NULL,
              last_seen INTEGER NOT NULL, created INTEGER NOT NULL);
             CREATE TABLE IF NOT EXISTS sessions(
              name TEXT PRIMARY KEY, ip TEXT NOT NULL, expires_at INTEGER NOT NULL);",
        )
        .map_err(|e| format!("migrate: {e}"))?;
        Ok(Self { conn: Mutex::new(conn) })
    }

    pub fn get_account(&self, name: &str) -> Result<Option<Account>, String> {
        let conn = self.conn.lock().map_err(|e| format!("lock: {e}"))?;
        conn.query_row(
            "SELECT name, uuid, premium_id, hash, last_ip, last_seen, created FROM accounts WHERE name = ?1",
            params![name.to_lowercase()],
            |r| {
                Ok(Account {
                    name: r.get(0)?,
                    uuid: r.get(1)?,
                    premium_id: r.get(2)?,
                    hash: r.get(3)?,
                    last_ip: r.get(4)?,
                    last_seen: r.get(5)?,
                    created: r.get(6)?,
                })
            },
        )
        .optional()
        .map_err(|e| format!("get_account: {e}"))
    }

    pub fn save_account(&self, acct: &Account) -> Result<(), String> {
        let conn = self.conn.lock().map_err(|e| format!("lock: {e}"))?;
        conn.execute(
            "INSERT INTO accounts(name, uuid, premium_id, hash, last_ip, last_seen, created)
             VALUES(?1,?2,?3,?4,?5,?6,?7)
             ON CONFLICT(name) DO UPDATE SET uuid=excluded.uuid, premium_id=excluded.premium_id,
               hash=excluded.hash, last_ip=excluded.last_ip, last_seen=excluded.last_seen",
            params![acct.name.to_lowercase(), acct.uuid, acct.premium_id, acct.hash, acct.last_ip, acct.last_seen, acct.created],
        )
        .map(|_| ())
        .map_err(|e| format!("save_account: {e}"))
    }

    pub fn delete_account(&self, name: &str) -> Result<(), String> {
        let conn = self.conn.lock().map_err(|e| format!("lock: {e}"))?;
        conn.execute("DELETE FROM accounts WHERE name = ?1", params![name.to_lowercase()])
            .map(|_| ())
            .map_err(|e| format!("delete_account: {e}"))
    }

    pub fn get_session(&self, name: &str) -> Result<Option<Session>, String> {
        let conn = self.conn.lock().map_err(|e| format!("lock: {e}"))?;
        conn.query_row(
            "SELECT name, ip, expires_at FROM sessions WHERE name = ?1",
            params![name.to_lowercase()],
            |r| Ok(Session { name: r.get(0)?, ip: r.get(1)?, expires_at: r.get::<_, i64>(2)? as u64 }),
        )
        .optional()
        .map_err(|e| format!("get_session: {e}"))
    }

    pub fn set_session(&self, s: &Session) -> Result<(), String> {
        let conn = self.conn.lock().map_err(|e| format!("lock: {e}"))?;
        conn.execute(
            "INSERT INTO sessions(name, ip, expires_at) VALUES(?1,?2,?3)
             ON CONFLICT(name) DO UPDATE SET ip=excluded.ip, expires_at=excluded.expires_at",
            params![s.name.to_lowercase(), s.ip, s.expires_at as i64],
        )
        .map(|_| ())
        .map_err(|e| format!("set_session: {e}"))
    }

    pub fn clear_session(&self, name: &str) -> Result<(), String> {
        let conn = self.conn.lock().map_err(|e| format!("lock: {e}"))?;
        conn.execute("DELETE FROM sessions WHERE name = ?1", params![name.to_lowercase()])
            .map(|_| ())
            .map_err(|e| format!("clear_session: {e}"))
    }
}
```

```rust
use crate::config::PluginConfig;
use crate::storage::Session;
use std::time::{SystemTime, UNIX_EPOCH};

pub fn now_secs() -> u64 {
    SystemTime::now()
        .duration_since(UNIX_EPOCH)
        .map(|d| d.as_secs())
        .unwrap_or(0)
}

pub fn new_expiry(now: u64, cfg: &PluginConfig) -> u64 {
```

```rust
use std::collections::HashMap;
use std::sync::Mutex;

pub struct PremiumCache {
    ttl: u64,
    inner: Mutex<HashMap<String, (bool, u64)>>,
}

impl PremiumCache {
    pub fn new(ttl_secs: u64) -> Self {
        Self { ttl: ttl_secs, inner: Mutex::new(HashMap::new()) }
    }
    pub fn get(&self, name: &str, now: u64) -> Option<bool> {
        let map = self.inner.lock().ok()?;
        let (v, at) = map.get(&name.to_lowercase())?;
        if now.saturating_sub(*at) < self.ttl {
            Some(*v)
        } else {
            None
        }
    }
    pub fn put(&self, name: String, is_premium: bool, now: u64) {
        if let Ok(mut map) = self.inner.lock() {
            map.insert(name.to_lowercase(), (is_premium, now));
        }
    }
}

        }
```
